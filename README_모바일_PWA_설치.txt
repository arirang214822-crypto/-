CAREER-FLOW NEXUS 모바일 v3.0 — 실행 및 설치 안내

1) 즉시 테스트
- CareerFlow_NEXUS_Mobile_v3.html 파일을 PC 브라우저에서 열어 기능을 확인합니다.
- 휴대폰에서 바로 테스트하려면 HTML 파일을 휴대폰으로 전송한 뒤 브라우저에서 엽니다. 기기·브라우저에 따라 로컬 파일 실행이 제한될 수 있습니다.
- 진단 데이터는 해당 브라우저의 localStorage에 저장됩니다. 다른 기기와 자동 동기화되지 않습니다.

2) 홈 화면 앱(PWA)으로 설치
- ZIP을 풀어 index.html, manifest.webmanifest, service-worker.js, 아이콘 파일을 같은 폴더에 둡니다.
- 이 폴더 전체를 HTTPS를 지원하는 정적 웹호스팅에 업로드합니다. index.html만 단독 업로드하면 설치·오프라인 캐시가 작동하지 않습니다.
- 스마트폰에서 배포된 HTTPS 주소를 엽니다.
  · Android/Chrome: 브라우저 메뉴 → 앱 설치 또는 홈 화면에 추가
  · iPhone/Safari: 공유 → 홈 화면에 추가
- 최초 접속 후 앱 셸은 캐시되어 오프라인에서도 열릴 수 있습니다. 외부 AI나 실시간 데이터 기능은 포함되어 있지 않습니다.

현재 포함
- 모바일 하단 내비게이션 및 추가 메뉴
- 6단계 통합진단, 10개 영역 준비도, 진로 경로 비교
- 개인 입력에 따른 90일 실행계획과 완료 체크
- A4 보고서 인쇄/PDF, 실행계획 TXT 내보내기
- 브라우저 내 저장, 전문가 검토 상태 시뮬레이션

중요한 한계
- 이 버전은 규칙 기반 시제품입니다. 실제 생성형 AI API, 채용공고·임금·훈련과정 실시간 연동, 서버 DB, 사용자 로그인, 기관별 권한, 기기간 동기화, 공식 전자승인은 연결되어 있지 않습니다.
- 개인정보와 민감정보를 입력하지 마세요. 상담·고용 관련 공식 결정 전에는 원자료와 전문가 검토가 필요합니다.
